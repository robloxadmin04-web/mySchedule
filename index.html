Features

Everything a student needs

Built for Filipino college students. Works with ICCT COR. Free forever.

S

Smart Schedule Import

Upload your COR PDF or screenshot and the app reads all classes automatically. Understands ICCT day codes like WSa, MTh, MWF.

T

Task Tracker

Track assignments per subject with due dates, priorities, and status. Sorted automatically by urgency.

G

Grade Calculator

Set up weighted grade categories per subject. See your running average in real time.

N

Notes

Write and organize class notes. Pin important ones. Search across everything instantly.

I

Image Storage

Save screenshots of lessons, whiteboard photos. Drag and drop to upload. Auto-backup before storage fills.

F

Focus Timer

Built-in Pomodoro timer. Study in focused intervals, track total study time automatically.

AI

AI Image Analysis

Connect a free API key (Gemini, Groq, OpenRouter) to scan schedule photos, extract grades from images.

SS

Session Saving

End-of-term: export everything as PDF, clear the semester data, get a fresh start. Schedule stays.

M

Mobile-First

Works on any device. No internet needed after loading. All data stays in your browser.

Settings → Export Backup (JSON) on old device. Send file to new device. On new device: Import Backup (JSON) → select file. All data restored.

Welcome to mySchedule

Your all-in-one student dashboard — schedule, tasks, grades, notes, and images. Everything in one place, saved on your device.

  • 📅 View your full weekly class schedule
  • ✅ Track assignments and deadlines
  • 📊 Monitor your grades per subject
  • 🖼️ Store screenshots and notes
📄

Import Your Schedule

Upload your COR (Certificate of Registration) PDF or a screenshot of your schedule — the app reads it automatically.

1Go to Schedule tab → tap Import from Image
2Upload your COR PDF or a photo of your schedule
3Review detected classes, edit if needed, then tap Import Selected

💡 Works even without an API key — the app reads PDF text automatically.

🤖

Unlock AI Features

Connect a free AI API key to get smarter image reading, grade extraction from photos, and subject detection from enrollment forms.

Without API key
✅ Import schedule from PDF
✅ Manual entry for all tabs
✅ Full app — tasks, grades, notes
❌ Photo-to-schedule (images)
❌ Photo-to-grades
With free API key
✅ Everything above
✅ Scan schedule from photo
✅ Extract grades from image
✅ Detect subjects from COR photo
✅ Better accuracy on any image
🔑

Get a Free API Key

These providers are free — no credit card needed. Sign up, copy your key, paste it in the app.

Google Gemini Recommended • Best for PDFs aistudio.google.com/apikey Groq Very fast • Great for text console.groq.com/keys OpenRouter Access to many free models openrouter.ai/keys

After getting your key: tap 🔑 API Key in any import modal → paste → Save.
